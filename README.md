Random Task Generator
Автор: Лика Хамидуллина

Описание
Генератор случайных задач с графическим интерфейсом (Tkinter). Позволяет выбрать случайную задачу из предопределённого списка, отображает историю сгенерированных задач с возможностью фильтрации по типу (учёба, спорт, работа). История сохраняется в файл tasks.json и загружается при запуске.

Возможности
Генерация случайной задачи.
История задач с фильтрацией по типу.
Сохранение и загрузка истории (JSON).
Проверка ошибок при работе с файлами.
Использование Git для контроля версий.
Требования
Python 3.8+
Библиотеки: tkinter (входит в стандартную библиотеку), random, json.
Запуск
Установите Python (если не установлен).
Клонируйте репозиторий.
Запустите main.py
